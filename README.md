# family-id

Собственный сервис регистрации и входа для моих проектов: провайдер OpenID Connect и сервер авторизации
OAuth 2.1 (в том числе для MCP-коннекторов Claude). Вход по passkey без паролей, единый вход и выход между
приложениями, три языка (ru / en / th). Первый клиент — «Семейная бухгалтерия»; сервис заменит Rauthy.

Статус: **этап 0 — ТЗ на согласовании**, кода пока нет.

- [Техническое задание](docs/spec.md)
- [План по этапам](docs/plan.md)
- [Архитектурные решения (ADR)](docs/adr/README.md)

Стек: Rust 2024, Axum 0.8, Askama, sqlx 0.8 + PostgreSQL 16, `webauthn-rs`. Архитектура — эталон `rust-hex-api`
(Cargo workspace, фича = крейт, порты и адаптеры).

Лицензия: MIT OR Apache-2.0 (файлы лицензий — с первым кодом, этап 0).
